# Ziva: information page

The public information page for **Ziva**, an everyday app from Cameroon: payments, rides, food and parcel delivery, and virtual phone numbers, in one app.

- **Live app:** [ziva.cm](https://ziva.cm)
- **Company:** Ziva Tech, Douala, Cameroon
- **Contact:** zivatech0@gmail.com

## What's here

A single static page (`index.html`) describing Ziva and linking to the app. It is published with GitHub Pages.

## Ziva at a glance

| | |
|---|---|
| **Rides** | Moto-taxis and taxis, fixed price before the trip, live tracking |
| **Food** | Restaurants receive orders on a dashboard; Ziva couriers deliver |
| **Parcels** | Delivered across town, handed over only with the recipient's code |
| **Payments** | Mobile Money, bills, airtime, transfers between Ziva users |
| **Numbers** | US and Canadian virtual numbers for SMS and calls |
| **Languages** | 10, including English, French and Arabic |
